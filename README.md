# The Most Boring Object, Reviewed in One Line

[![make.fun bounty](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/c/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3)

One line, at most 200 characters, reviewing the most boring everyday object — for the [make.fun bounty](https://make.fun/c/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3).

> The twist tie has been untwisted and retwisted a hundred times to keep the bread fresh, and still falls off the second the bag tips over.

## How it works

`main.ts` writes the review line to `/output/entry.txt` and prints it to stdout. Pure Node, no dependencies.

## Run

```sh
node main.ts
```
